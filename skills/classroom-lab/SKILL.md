# 课堂实验动画

把老师说的实验或科学过程做出来。默认交付一个可直接插入 PPT 的有声 MP4；需要调参、学生操作或用户明确要网页时，再附独立 HTML。不要把脚本、网页、方案或分镜当作已完成的视频。

## 一句话开始

用户只给实验名也直接制作。默认中文、经过视觉设计的实验主体、清晰的大字、16:9 横屏 1920×1080、30fps、约半分钟到一分钟、普通话讲解和简短字幕；按知识难度推定适合的学段，在交付时用一句话说明即可。用户已给的年级、时长、风格、格式优先。

不要先让老师填年级、配色、尺寸、音色、模型、API Key 或工具选择表。仅当缺失信息会改变实验对象/科学结论、确实无法合理推定时，问一个短问题。实验含糊时可以说明一个合理解释后制作；例如“浮力实验”默认演示浸入体积与浮力，而不是等待完整教案。

尊重用户原始命题。若它科学上有误（如“证明重物一定下落更快”），简短纠正并演示正确的对照，不按错误命题捏造结果。

## 按题目选科学表达

范围包括物理、化学和生物，不以现有示例为白名单。先判断用户要看的是宏观实验、微观机制、生命过程，还是可调模拟；概念过程不强行包装成做过的真实实验。

- 物理：力、光、电、运动等，核对量纲、方向和模型适用范围。
- 化学：先读 [化学制作与核验](references/chemistry.md)，处理宏观现象、粒子机制和符号表达之间的对应关系。
- 生物：先读 [生物制作与核验](references/biology.md)，选定细胞/组织/个体层级，核对结构、阶段和数量关系。
- 跨学科：按本题涉及的机制组合检查，不要求用户先选择学科。

## 制作

1. 在内部明确一个要观察的现象或机制。可调实验明确操纵变量和不变条件；生命过程明确阶段及连续变化。安排“预测→观察→解释”的推进。围绕实验对象发生变化，避免只有文字卡片和装饰动画。没有实际测量时将数值标为模型计算，不能写成实验实测。
2. 查明科学关系和适用范围。读 [科学核验](references/science-check.md)；遇到陌生或不确定的关系，核对教材、大学或科学机构原始资料。没有网络时如实记录依据与未核验项，不伪造引用。知识核验由代理完成，不要求老师先查资料。
3. 先读 [视觉与动效](references/visual-motion.md) 和 [MP4交付](references/video-export.md)。按实验选择三维、SVG或Canvas，制作前确认有可用的实际视频渲染路径；不要先做出无法导出的视频方案。默认 H.264 / yuv420p 视频、AAC 音频的 MP4，教师无需安装运行时、录屏或转换格式。渲染依赖由代理准备；视频画面只留实验、必要标注和字幕，不录入网页按钮、滑块或浏览器边框。保持运镜和科学可读性，不为了导出静默把三维降成平面。
4. 视频将有意义的参数变化安排进时间轴，保留预测和观察停顿。只有需要互动时才附 HTML，提供播放/暂停、重播、分步查看、隐藏/显示结论；适合调参的实验再加滑块。可复用 [播放模板](assets/player.html) 和 [网页构建说明](references/build-contract.md)，保持无CDN、无字体下载、无服务器依赖。两种格式共用科学模型与讲解，画面、数值和解释必须对应。不要让老师填格式表才能看到首版。
5. 在新的输出目录保存成品和可修改源文件。默认沿用老师上一版继续改；需要改模型时复核结果。不要改 Skill 安装目录里的模板来完成单次课程。

## 检查后交付

实际运行新代码。先核对模型，再检查实际成片；“文件生成成功”不等于实验正确。

- 用独立手算值检查典型情况、一个边界和一个反例。绘制、数字标签、结论共用同一个状态；不得滑块动了但结论固定。
- MP4 核对尺寸、帧率、时长、视频/音频编码及完整解码；抽取最终成片开头、变化过程、转场和结尾检查遮挡、中文字体、字幕和模型对应关系。正常速度回看动画与讲解，未完成的听审、播放或PPT插入实测明确注明。导出失败时继续处理可解决的问题；确实缺少能力时说明阻碍和当前可用产物，不能把HTML改后缀或把网页当MP4交差。
- 如果附 HTML，用可用的浏览器工具实际打开最终 HTML，操作播放、暂停、重播、切阶段、改参数、显示结论；检查开始/中间/结束画面、标签遮挡、窄屏和控制区可达性。复用模板也要检查新场景。没有浏览器工具时交付并明确“未完成浏览器实测”，不要声称通过。
- 三维成片检查镜头落定、器材和数值对应、标注可读性；附网页时另外核对窄屏、暂停及 WebGL 不可用时的兼容视图。预测阶段在提问讲完并留出思考时间前，不用运动或标签提前揭示答案。
- 自包含结果在断网或禁止外网请求时应正常演示。音频另行说明。涉及播放兼容时，以实际测试过的浏览器为准。
- 只修复实测发现的问题；不为每个简单动画启动复杂测试工程。不确定的科学结论不能用醒目效果掩盖。

交付回复尽量短：**MP4预览/下载链接 + “可插入PPT” + 必要的模型边界**。互动HTML、源文件和核验说明作为次级入口，不把老师带到工程目录找成品。老师可以继续说“慢一点”“给四年级看”“加一个错误示范”来修改。

## 旁白与格式

默认带普通话讲解，同时提供按阶段对应的短讲解稿。先读取 [旁白与导出](references/narration.md)，使用实际可用且已授权的语音能力生成音频并合入视频；附网页时也内嵌音频；不先让老师选择声音或配置API。只有用户明确要无声时才省略旁白。没有可用配音能力时，明确说明缺失并先交付可用动画，不能把只有文字稿称为有声完成。

MP4是默认交付，可在PPT中作为视频插入；它不是可编辑PPT图形，也不保留滑块交互。用户明确指定HTML、无声、其他画幅或格式时遵从。
