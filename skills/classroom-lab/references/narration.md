# 默认讲解与可选音色

默认生成普通话讲解并合入MP4；附网页时也内嵌音频。用户只需点播放；不先问声音、Key或服务。不要求静音的用户应拿到可听到的音频，文字讲稿不能代替声音。

## 选用当前实际能力

优先沿用本任务中用户已选定的声音；未指定时，优先使用微软普通话女声“晓晓” `zh-CN-XiaoxiaoNeural`，语速 `+5%`。它是本Skill量筒参考样片所用的普通声音，无需私人录音或本地声音模型。不要给安装者增加作者的私人音色依赖。

用户要求沿用以前作品的声音时，先查那件作品的实际配音记录，核对声音来源和表达设置，再生成；不要把“都有普通话”当作同一个音色。私人参考录音和模型只在授权环境中使用，不打进公共Skill包。示例内的成品音频不代表安装者拥有同一声音的生成能力。

### 晓晓：优先方案

代理可运行 [在线配音辅助器](../scripts/narrate_edge.py)，需要Python、edge-tts、ffmpeg与ffprobe。依赖由代理在可用环境中准备，不要求老师操作终端或填API Key。已有uv时可在隔离环境调用：

```sh
uv run --with edge-tts==7.3.1 python /实际Skill路径/scripts/narrate_edge.py --lesson /输出目录/lesson.json
```

已有音频的本次修订加 `--force`；可重复传入 `--lesson` 批量制作。辅助器先生成全部片段，再替换源文件；记录音色和实际时长，必要时延长阶段，随后重新导出MP4；附网页时也重新构建HTML。`--voice` 和 `--rate` 可按用户要求改动。

生成会把讲解文字发送到Edge在线语音服务，需要联网；内嵌后的网页播放不联网。edge-tts是第三方客户端，服务可用性不由Skill保证。2026-10-20实测7.3.1可用，旧7.2.8收到403；连接失败时先检查受支持的当前版本，仍失败则明确说明，不冒充指定声音或静默换成私人克隆音色。项目说明见 [edge-tts](https://github.com/rany2/edge-tts)。

### 本地系统声音：可选替代

本机macOS可选用系统语音作为低配置基础实现。确认 `say`、`ffmpeg` 和 `ffprobe` 可用，且 `say -v '?'` 中有目标声音，再由代理运行：

```sh
python3 /实际Skill路径/scripts/narrate_macos.py --lesson /输出目录/lesson.json
```

此辅助器默认Tingting、语速190，生成各阶段MP3，记录实际时长，必要时延长阶段；已有源文件需先确认是本次修订目标。它是macOS可选工具，不是本Skill默认声音或跨平台强制依赖，也不要求老师运行命令。使用替代声音时明确告知；不得声称已测试未用过的服务。

没有可用语音能力时不偷偷启用付费服务。先交付动画并明确指出讲解音频未完成，保留讲稿与后续接入口。

## 嵌入与同步

每个阶段可设置 `audioFile`（相对于lesson.json的文件路径）、`audioDuration`（秒）。构建器将音频转成内嵌数据，不依赖播放时联网。讲解时长不能超过该阶段；保留适量观察停顿。

默认模板提供“讲解：开/关”，播放、暂停、定位、切阶段与重播控制同一个音频元素。教师手动改参数后暂停固定讲解，防止讲述旧条件；重播或进入预设步骤恢复。若需要动态讲解手调结果，应实现对应语音，不能继续播放不相符的固定稿。

实际测试音频可解码、有非静音内容、时间推进与暂停/重播同步；核对数字和单位。测试数字流不等同于人工完整听审。

## 后续选择音色

用户明确想选声音时，从真实可用的声音中最多提供三个试听。名称、语言和费用以实际能力为准，不伪造试听或预先要求用户付费。

MP4默认导出流程见 [MP4交付](video-export.md)，按各阶段起点合成讲解，视频和声音共用时间轴。原生可编辑PPTX另需制作；不能把网页改后缀当成视频。
