# 科学核验：按实验需要读取

核心是教学现象可靠，不追求把每个演示都做成完整科学仿真引擎。

## 模型与演示分开

- **过程动画**：按已知顺序展示变化。时间压缩、尺度夸张和示意运动需要简短标注。
- **可调模拟**：输出由输入和模型计算。整个开放参数范围都应合理；超出模型适用范围时限制参数或说明。
- **真实实验**：模型输出不冒充实测。动画不是做过实体实验的证据。

在源文件或核验说明中保留：输入及单位、主要关系、假设、两个以上可手算例子、已查来源。成品只露出老师/学生需要的简短说明，其余折叠。

## 常见易错点

| 实验 | 必须核对 |
|---|---|
| 杠杆 | 力矩是力×垂直力臂；若用质量比较，需要两侧处于同一重力场。杆质量/摩擦是否忽略？倾斜角和转速若只是示意，要明确，不能称真实平衡角。 |
| 量筒 | 凹液面读最低处、视线水平。俯视/仰视要依据视线与刻度位置作几何核对，不能只切换一段文字。凸液面与不同器皿不能直接沿用。 |
| 单摆 | 小角度 T=2π√(L/g)，L是悬点到摆球质心的长度。质量不影响该模型周期；改变摆长时保持其他条件一致。限制小摆角，不能声称大角度也严格成立。 |
| 光学 | 光线传播方向、法线、角度基准和折射率；全反射只可能从高折射率到低折射率且超过临界角。阴影、反射与折射不能混用。 |
| 电路 | 区分断路和短路、串并联；电压电流单位一致。颜色/亮度映射要来自模型，不凭视觉喜好推断功率。 |
| 化学 | 元素/电荷守恒、化学计量、物态与条件。盐溶解、化学反应、电离不是同一机制；粒子颜色不是溶液真实颜色。读[化学核验](chemistry.md)。 |
| 生物 | 明确物种/细胞类型、结构层级、阶段与统计范围；核DNA/染色体/染色单体分别计数。过程时间、概率和大小不能伪装实测。读[生物核验](biology.md)。 |

## 检查例子

以杠杆为例：左100 g×20 cm，右50 g×40 cm应平衡；右臂改为20 cm应左沉；左右同时交换应反向。图像、标签、判断三者都要跟着变。

不要仅用实现函数生成自己的“预期答案”。优先手算常数、对称性、单调性或独立公式，并测试视觉标注是否也使用同样的单位。一个案例的通过不能外推到所有实验。
