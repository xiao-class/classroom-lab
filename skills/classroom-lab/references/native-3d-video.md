# 真正的三维教学 MP4

实体器材、空间关系和用户明确的三维要求，使用实际三维几何、灯光、材质、相机渲染。下列流程已用于杠杆、单摆、折射、氯化钠溶解和动物细胞有丝分裂五支有声教学成片；它不是把宣传片剪进每个实验，也不把2D加阴影称为三维。

## 已实现的 macOS 原生路径

`scripts/export_3d.py` 调用同目录 `native-3d/Render.swift`，用 SceneKit / Metal 离屏绘制真实三维场景，再将 RGBA 帧交给 FFmpeg。没有浏览器、WebView、录屏或本地网页访问。适用于具有 Metal 的 macOS，需 Swift（Xcode Command Line Tools）、Python 3、FFmpeg/ffprobe。依赖由代理准备，教师只收到 MP4。字体通过 macOS AppKit 使用本机中文字体，不复制或分发系统字体。

其他系统不运行这个后端。选择环境允许的 Three.js/Remotion、Blender 等真实三维渲染路径，并验证实际成片；本包没有声称附带跨平台的三维渲染器。缺少能力时解决实际依赖或说明阻碍，不能用平面样片代替已要求的三维。

## 直接制作五个示例

物理样例位于 `assets/physics-3d/` 下的 `lever`、`pendulum` 和 `refraction`；化学/生物位于 `assets/life-3d/dissolution` 和 `assets/life-3d/mitosis`。把选中的整个目录复制到本次课程输出目录，保留 audio。不要在安装目录修改样例。代理执行：

```sh
python3 /Skill路径/scripts/export_3d.py \
  --lesson /课程目录/lesson.json \
  --out /课程目录/实验动画.mp4
```

默认1920×1080、30fps、H.264/yuv420p、AAC 48kHz双声道、faststart。先抽几个关键时刻检查，再全片渲染：

```sh
python3 /Skill路径/scripts/export_3d.py \
  --lesson /课程目录/lesson.json \
  --out /课程目录/画面检查 --preview 0,3,10,15,26,32
```

`--preview` 输出PNG与对应states.json，不冒充MP4。正式导出先写临时文件，通过帧数、时长、编码、完整解码后才替换成品；已有目标需要本次修订的 `--force`。缺音频、音频超出阶段、未知场景或超出几何容纳范围会失败并保留旧视频。编译文件与中间帧不打包进Skill。

## 改内容时实际改什么

- `lesson.json` 决定标题、阶段起点、参数、讲解、实际音频。`sceneType` 当前为 lever / pendulum / refraction / dissolution / mitosis。字幕按短句字数分配在音频实际时长内，不是逐字强制对齐。
- `native-3d/models.py` 生成确定性状态，模型数值、三维几何和屏幕标注共用这一状态；跳转时间与顺序播放结果相同。
- `native-3d/Render.swift` 实现五种场景、材质、相机与排版。开头约3.2秒从斜视角转至稳定观察角，讲解期间不持续绕场。光路精确比较时采用正视角，同时保留立体水槽。
- 新题仍需新增/修改正确的科学模型与相应几何。改`sceneType`或标题不能创造新的实验。渲染器没有为任意题目生成模型的能力，代理承担设计与核验。

当前几何检查范围：杠杆左臂固定20cm，砝码50–200g，右距10–40cm；单摆左侧0.50m/50g，右长0.50–1.00m、质量50–200g，8°小角度；折射为空气n=1到水n=1.33，入射角0–75°。这些是样例的构图和模型边界，不限制Skill的题目范围。超出时需要同时改几何、镜头、状态、解释与检查，不能只放宽校验。

三个样例分别为3/3/4阶段，过渡节奏也是教学安排的一部分。尤其杠杆预测要等提问录音结束再留1秒，之后才显出倾斜；右侧移动期间显示实际过渡距离和力矩。倾斜速度与幅度是示意，不声称为动力学仿真。单摆按真实秒数与小角度周期公式运动，改变质量不改变几何摆长。折射前后用同色光束，角度从法线量起，光点速度只是方向提示。

## 完成检查

每次改动都查看最终MP4抽帧，尤其预测揭示时点、参数变化、三维镜头落定、标题与标签、字幕和实验主体是否遮挡。确认真实音轨存在且不截断，保留原音色；将“拖滑块”等交互文案改为视频的观察提示。`*.qa/verification.json` 默认把视觉和听审标为pending，代理完成实际检查后另记结论，不能因为编码成功就标全部通过。PPT/WPS兼容以实际插入测试为准。

科学依据见各示例lesson.sources。工程API参考[Apple SCNRenderer](https://developer.apple.com/documentation/scenekit/scnrenderer)，SceneKit是此macOS后端的实现选择，不是安装者的跨平台要求。

## 化学与生物三维配方

两个过程保留原来的四段晓晓音频，默认52秒/56秒。`native-3d/life_models.py` 持续追踪离子和DNA身份，`models.py`把每阶段实际时长映射到教学过程，延长阶段会同步放慢运动，音频仍在阶段起点开始。当前为固定内容的定性过程，不接受未经实现的参数或values；改物质、细胞类型、倍性或粒子数时需同时改模型和几何，不能只改标题。

- 溶解：5×2×2交替离子晶格片段，10个Na⁺和10个Cl⁻保持身份和电荷。分散时已出现伴随的水分子；第3阶段是代表离子的水合放大，不额外计数。氧为红色、氢为白色；水分子氧端朝Na⁺，氢端朝Cl⁻。水合壳画出的6个水分子用于说明朝向，不声称实际固定配位数、溶解动力学或饱和度。
- 有丝分裂：动物细胞2n=4，膜与核膜用真实三维剖开曲面显示内部。8条DNA线迹始终保留，前期/中期4条染色体，后期同一细胞8条，胞质分裂后各4条；姐妹分别到达两极。核膜重建后才完成缢裂；去凝缩由原线迹形变而来，不叠加第二套DNA。前期/前中期合并、时间/尺寸为示意，不套到植物细胞或减数分裂。

抽帧应覆盖水合朝向、分散期间的粒子追踪、核膜透明/剖切遮挡、纺锤体连接、姐妹分离、缢裂中间与两个子细胞。科学来源见各lesson.sources与学科参考。


## 顺滑度（本版新增）

- `export_3d.py` 默认 `--motion-blur 4 --shutter 0.5`：每帧渲染 4 个子帧并在 FFmpeg 中平均，形成 180° 快门模糊；`--motion-blur 1` 关闭（耗时约为 4 倍）。预览模式不加模糊。
- 字幕、结论、数值卡、阶段名换句时自动淡出/淡入（数字随参数连续变化时不淡变）。
- 杠杆换砝码在约 1.2 秒内连续完成，横梁随之转动；标签只显示真实砝码值。开场推镜后保持极慢推进，不环绕。
- `tests/test_native_3d.py::test_no_snaps_between_frames` 逐帧检查角度与质量不跳变；新增场景请加入同样的检查。
