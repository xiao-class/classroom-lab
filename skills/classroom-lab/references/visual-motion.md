# 视觉与动效：让实验本身有吸引力

教师仍只说实验。由代理选镜头、材质和技术，不增加选择表。目标是像高质量科学演示一样可看、可讲、可操作；分享视频中的概念开场不是科学测量，也不能保证一句提示在所有代理上产生完全同样的电影效果。

## 表现选择

- 实体器材和空间关系：优先考虑三维。杠杆的支架、砝码与刻度；量筒的圆柱、液面与视线；单摆的摆线与球体。物体结构与变化承担主要视觉效果。
- 化学微观过程：晶格、离子、分子、溶剂包围与宏微观切换；颜色对应图例，不能冒充溶液真实颜色。
- 生物结构与生命过程：细胞膜/细胞器的半透明层次、染色体形变、物质运输、局部剖切；观察尺度与物种明确。
- 平面光路、曲线及精确读数：用适合内容的 SVG/Canvas，同样可用层次、轮廓、光晕和有节奏的显现；不要为三维牺牲读数准确性。
- 老设备、WebGL 不可用或用户要求简洁：给有明确前后层次、关键位置突出、时间推进清楚的平面场景。交付时说明实际采用的方式，不把平面称为三维。

## 从吸引注意到看清现象

可以先用约2–4秒器材入场或镜头推近，再落到适合观察的固定视角；不为每个实验强塞片头。讲预测时先停住，不提前倾斜、变色或写出答案。镜头不循环摇摆，不绕过量筒读数的水平视线。参数滑动后，图形、标签、解释共用当前模型；有动画过渡就显示过渡中的实际值。

在一个场景中确立主光、材质层次和清晰轮廓；金属、玻璃、水分别有合适表现。发光适合突出光束、接触点等，不能让整幅画面泛白。镜头停稳后大字能读，标尺与单位不能被景深、透明面或装饰遮挡。长段说明放配套讲解稿，不贴进三维空间。网页尊重系统减少动态效果的设置，保留教学现象但减少镜头运动。

## 可直接复用的三维网页基础

默认MP4的实际渲染路径见 [MP4交付](video-export.md)。下面资源是网页运行库，不是MP4导出器；需要三维成片时先确认有可用的三维渲染流程。

- [本地运行库](../assets/three-stage/runtime.min.js)：`Lab3D.T` 是 Three.js；`Lab3D.createStage(svg)` 建立 Canvas、场景、相机、主光/轮廓光、环境反射、地面、尺寸适配。无需服务器或 CDN。
- [基础源码](../assets/three-stage/stage.js)：可按实验修改；默认配色、地面与相机不是统一硬性风格。
- [完整三维杠杆](../assets/lever-3d-demo/scene.js) 和 [配置](../assets/lever-3d-demo/lesson.json)：包括同模型 SVG 兼容视图、8.5秒预测留白、原有晓晓讲解、滑块和动态解释。复制整个 demo 目录到输出目录后修改，不改安装模板。
- [构建接口](build-contract.md#三维场景与本地库)：`--library` 把运行库内嵌为单文件。音频也内嵌。

舞台返回 `scene, camera, mesh, material, label, draw, onResize, dispose, reducedMotion`。`mesh(geometry, material, parent?, position?)` 返回 Mesh；`label(text, color?)` 返回 Sprite；`onResize(fn)` 用最后一份状态重画。每次 render 只按传入状态更新物体和相机，再 draw，不累计时间。文本变化才重建字图，并释放旧纹理。

需要新的三维实验时，代理仍要实现该题的正确模型和几何，基础库不会自动理解任意实验。不能把复制杠杆、更换标题称作已支持另一个实验。

## 验证边界

模型数值与方向先核对；再检查最终视频初始/观察/结束、字幕和音画同步。附互动网页时另外检查拖动参数、暂停、重播、手机布局、WebGL失效兼容。既有示例或视频漂亮，不等于新题已经通过视觉检查。工具打不开时提供可打开的成品，明确未完成的浏览器实测，不虚构截图或验收。
