# 成片评审：交付前让“另一双眼睛”打分

做完 MP4 后，用下列提示词让一个**没有参与制作**的子代理（或新会话）评审成片，再按意见改一轮。思路借鉴 mg-styles-15 的“制作 → 独立评审 → 修改”循环，评分维度换成课堂需求。

## 评审提示词

```text
你是严格的课堂教学视频评审（物理/化学/生物教研员 + 动态设计总监）。你没有参与制作，请具体、苛刻地评审：
成片：<MP4 路径>   lesson.json：<路径>   学段：<年级>

1. 先看片：每 0.5 秒抽一帧拼接触表；每个阶段切换点前后各抽 10 帧；关键结论帧看原尺寸。
2. 规格：1920×1080、30fps、H.264/AAC、时长与 lesson 一致、旁白完整不截断、响度约 -16 LUFS、真峰值 ≤ -1 dBTP。
3. 1–10 打分（5=能用，7=专业，9=可做示范课）：
   - science：数值、方向、单位、结论与模型一致；没有把示意写成实测
   - pedagogy：预测→观察→解释是否成立；提问讲完后是否留了思考时间；没有提前泄露答案
   - readability：在教室投影上，字幕、标签、数值能否看清；主体是否足够大
   - motion：有无瞬移、换字闪烁、白闪、硬切；缓动与落定；快门模糊
   - sync：标注出现与讲解是否同步；字幕是否和声音对得上
   - finish：材质、光线、锯齿、色带、字体缺字
4. 按影响排序给 5–8 条修改，每条写：时间码、看到了什么、为什么影响课堂、怎么改（具体到秒数、像素、曲线）。
5. 标红：任何科学错误、答案提前出现、看不清的关键数值、缺字/豆腐块。
```

## 修改轮

- 先保留当前版本，再改；只改评审指出的问题和明确更好的方案，不回退评审认可的部分。
- 科学类问题优先于观感问题。改完重新导出、重新抽帧确认问题已解决，在 `.qa/verification.json` 记录评审分数与处理结果。
- 评审本身也会出错：与 lesson.sources 或教材冲突时以资料为准，并在交付说明里写明。
